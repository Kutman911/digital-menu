# Coffee QR Menu ☕

Электронное меню для кофейни по QR-коду.  
Полностью адаптивное, два языка (RU/EN), админка для изменения меню без программиста.

## Технологии
- Backend: Java 21 + Spring Boot 3
- Frontend: React 18 + Vite + Tailwind CSS
- БД: PostgreSQL
- Фото: локальное хранение + оптимизация или Cloudinary
